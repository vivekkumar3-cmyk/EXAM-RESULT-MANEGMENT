# Exam Result Management System

## Project Information

Project Number: 49

Project Title: Exam Result Management System

Language: Python 3

## Description

This project is designed to manage
student examination records.

It stores student marks in three subjects:

1. Maths
2. Physics
3. Chemistry

## Features

- Add Student Records
- View All Records
- Calculate Total Marks
- Calculate Percentage
- Pass and Fail Result
- Generate Rank List
- File Handling

## Concepts Used

- Python Functions
- Lists
- Dictionaries
- Conditional Statements
- Loops
- Sorting
- File Handling

## How to Run

Run the following command:

python one.py

## Pass Criteria

A student must score at least
40 marks in each subject to pass.
