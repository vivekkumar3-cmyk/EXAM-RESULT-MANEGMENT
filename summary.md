# Project Summary

## Project Title
Exam Result Management System

## Objective

The objective of this project is to
manage student examination records
and calculate their results.

## Problem Statement

Create a Python system that stores
student records with marks in three
subjects, calculates total marks,
percentage and result, and generates
a rank list.

## Technologies Used

- Python 3
- VS Code
- JSON File Handling

## Main Functions

1. load_records()
2. save_records()
3. calculate_result()
4. add_student()
5. view_records()
6. rank_list()
7. main()

## Test Cases

1. Normal Input
2. Minimum Marks
3. Invalid Input
4. Rank List

## Conclusion

The Exam Result Management System
successfully manages student records,
calculates examination results and
generates a rank list based on total marks.
